ThreatLens

Threat modeling as code. Describe a system's trust zones, components and data flows in YAML; ThreatLens draws the data-flow diagram, runs a 35-rule STRIDE knowledge base focused on access, abuse and logging, scores each threat, and emits Markdown and SARIF. The Python engine runs in this page through Pyodide.
